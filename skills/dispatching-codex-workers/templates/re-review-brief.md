## SHA дельты

Прошлое ревью: `[prev_review_sha]` — коммит, который видел прошлый ревьюер. Текущий:
`[current_sha]` — коммит, которым автор сохранил доработку перед этим ревью (без push).

Диапазон строго `git diff [prev_review_sha]..[current_sha]` — это не весь проект и не исходный
change-set от базового SHA первого ревью. Незакоммиченная работа на ревью не отдаётся: если
рабочее дерево на момент запуска отличается от `[current_sha]`, сообщи об этом координатору через
`ask`, не начинай ревью.

## Отчёт

Первая строка: `DONE` при PASS всех перечисленных находок, иначе `DONE_WITH_CONCERNS` или
`BLOCKED` с причиной.
Далее: `[ID] — PASS/FAIL — доказательство из diff`; затем отдельный список новых находок вне
scope без расширенного анализа. Заверши `worker_done` с подходящим `--outcome succeeded|failed`.

Поле пакета свидетельств: строка `Расход:` из `session-usage`; при ошибке —
`Расход: не получен — <причина>`. Запусти скрипт перед `worker_done`.
